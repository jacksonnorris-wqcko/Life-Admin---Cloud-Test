# Life Admin V12.1.0 — Family Beta

Life Admin is a mobile-first personal admin app with optional account-based sync across devices.

## Beta build
- Refreshed visual system and mobile UI polish
- Cleaner account creation and sign-in experience
- Password reset flow
- Friendly authentication error messages
- Supabase authentication and cloud snapshot sync retained
- Local document storage retained for this beta
- Eight appearance themes
- Local backup/export and import

## Sync
Account sync stores Life Admin items, calendar events and settings in the configured Supabase project. Documents remain on the individual device for now.

## Deployment
This build is intended for family/friend beta testing through the hosted PWA.
